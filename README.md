#### Repository Structure

This repository contains a SolidWorks CAD project with the following components:

- **Assembly File**: `Assemf.SLDASM` - The main assembly file
- **Part Files** (in `part/` directory):
  - Vehicle chassis components (Front chassis, Rear chassis, Rear bumper)
  - Engine housing
  - Body components (Hood, Doors, Roof)
  - Steering components (Steering wheel assembly, Steering column)
  - Wheels and related parts
  - Gears (in `part/gears/` subdirectory)
  - Pins (in `part/pins/` subdirectory)

#### Important Notes on RTIA

1. **RTIA is not a standard SolidWorks parameter** - It may be a custom parameter, equation variable, or design table value specific to your project.

2. **SolidWorks binary files cannot be searched as text** - The .SLDPRT and .SLDASM files are binary formats. To find and modify RTIA:
   - Open the files in SolidWorks
   - Check **Equations** (Tools > Equations) for any variables named RTIA
   - Check **Design Tables** (if any) for RTIA columns
   - Check **Custom Properties** (File > Properties) for RTIA values
   - Check **Configurations** for any RTIA-related parameters

3. **To modify RTIA in SolidWorks**:
   - If it's in Equations: Edit the equation value directly
   - If it's a dimension: Double-click the feature and modify the dimension
   - If it's in a Design Table: Edit the linked Excel spreadsheet
   - If it's a Global Variable: Modify it in the Equations dialog

#### הערות חשובות על RTIA

1. **RTIA אינו פרמטר סטנדרטי ב-SolidWorks** - ייתכן שזהו פרמטר מותאם אישית, משתנה משוואות, או ערך בטבלת עיצוב ספציפי לפרויקט שלך.

2. **לא ניתן לחפש קבצי SolidWorks בינאריים כטקסט** - קבצי SLDPRT ו-SLDASM הם בפורמט בינארי. כדי למצוא ולשנות את RTIA:
   - פתח את הקבצים ב-SolidWorks
   - בדוק **משוואות** (Tools > Equations) עבור משתנים בשם RTIA
   - בדוק **טבלאות עיצוב** (אם יש) עבור עמודות RTIA
   - בדוק **מאפיינים מותאמים אישית** (File > Properties) עבור ערכי RTIA
   - בדוק **תצורות** עבור פרמטרים הקשורים ל-RTIA

3. **כדי לשנות את RTIA ב-SolidWorks**:
   - אם הוא במשוואות: ערוך ישירות את ערך המשוואה
   - אם זה מימד: לחץ פעמיים על הפיצ'ר ושנה את המימד
   - אם הוא בטבלת עיצוב: ערוך את גיליון האקסל המקושר
   - אם זה משתנה גלובלי: שנה אותו בדיאלוג המשוואות
